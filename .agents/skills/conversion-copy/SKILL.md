# Czech conversion copy

## Voice

Sound like a competent local specialist: calm, direct, understandable and respectful. Avoid corporate filler, forced humor, panic-based security messaging and unsupported superlatives.

## Message hierarchy

1. Situation: renovation or need to coordinate electrical work.
2. Outcome: a safe, practical installation planned around the home and future use.
3. Scope: primary renovation wiring plus relevant connected services.
4. Proof: only client-approved evidence.
5. Next step: a low-friction, accurately described contact action.

## Writing rules

- Use short paragraphs, concrete verbs and reader-centered benefits.
- Translate technical features into practical impact without removing necessary precision.
- Keep “rekonstrukce” and core electrical work prominent; do not let smart-home/security copy take over the homepage.
- Write CTA labels that describe the action and context.
- Keep headings meaningful when read alone.
- Do not overuse exclamation marks, “komplexní řešení”, “na míru” or “kvalita” without evidence.
- Do not manufacture urgency, scarcity, prices, turnaround or guarantees.
- If tone of address (`vy` versus `Vy`) is not established, preserve the current site convention and flag inconsistency.

## Form copy

Ask only for information required to start the conversation. Use persistent labels and examples only as supporting hints. Explain optional fields. State follow-up timing/channel only when confirmed. Separate privacy information from optional marketing consent.

## Review output

For each proposed change show: current wording, proposed wording, user concern addressed and any fact needing client approval. Preserve approved brand phrases unless there is a clear usability, factual or legal issue.
